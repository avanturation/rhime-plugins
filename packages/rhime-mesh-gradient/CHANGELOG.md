# Changelog

## 1.11.0 · 2026-10-02

- 플러그인 패널을 Rhime의 회색 바탕, 둥근 흰 카드, 캡슐형 버튼과 검정 선택 상태로 정리했습니다.
- Interlude 1.3 전체 가변 폰트를 내장하고 HEX·OKLCH·진단 텍스트의 모노스페이스 지정을 제거했습니다. 별도 폰트 설치나 외부 연결 없이 표시됩니다.
- 패널 크기와 프리뷰 여백을 조정해 iPhone·Duo의 하단 안내가 보이도록 했습니다.
- Figma 데스크톱에서 두 크기의 UI를 확인하고 기존 자동 테스트 59개를 통과했습니다.

## 1.10.0 · 2026-09-26

- iPhone Duo 953 × 671 크기 선택을 추가했습니다. 기존 iPhone 402 × 874도 유지합니다.
- 프리뷰 캔버스, 포인트 오버레이, PNG 해상도, Shader 프레임·레이어를 선택한 크기에 맞춥니다.
- 크기 전환 시 현재 색 흐름과 재생을 유지하고, 저장 중 크기를 바꿔도 클릭 당시 규격을 보존합니다.
- 59개 자동 테스트 통과.

## 1.9.0 · 2026-09-26

- 기본 출력을 현재 프리뷰의 402 × 874 PNG로 변경했습니다. Shader 출력은 별도 버튼으로 유지합니다.
- 프리뷰와 저장에 같은 합성 캔버스를 사용하고, 피그마에서 블러·투명도·베일을 중복 적용하지 않습니다.
- 재생 중 클릭한 프레임을 인코딩 전에 복사합니다. 실제 Shader 렌더를 보고 있을 때는 해당 이미지를 저장합니다.
- Shader가 연결되지 않아도 기본 PNG를 생성할 수 있습니다.
- 55개 자동 테스트 통과.

## 1.8.0 · 2026-09-18

- 앨범/가사의 배경 차이를 없애고 중간 대비 팔레트, Blur 36px, 베일 8%로 통일했습니다.
- 일반 앨범 화면에도 네 가지 오디오 색 흐름을 적용합니다.
- 앨범/가사 전환은 콘텐츠만 바꾸며, 재생·색·흐름 위상·일시정지 및 네이티브 미리보기를 유지합니다.
- 부드럽게 / 균형 / 또렷하게 프리셋은 화면 구성과 독립적으로 적용됩니다.
- 공통 네이티브 출력과 화면 전환 시 스냅샷 보존을 포함한 52개 테스트 통과.


## 1.7.0 · 2026-09-18

- 일반 뷰는 기존 1.6의 은은한 배경을 유지하고, 가사 뷰에 들어갈 때만 경계와 명암을 선명하게 표시합니다. 일반 / 가사 전환을 추가했습니다.
- 가사 뷰 음악 재생 시 Mesh 포인트를 고정하고 색만 이동하는 `color-flow-v2`로 교체했습니다. 생성할 때도 같은 좌표에 현재 색을 저장합니다.
- 저음 / 보컬 추정 / 드럼 / 악기·신스 추정의 네 반응과 개별 0–200% 조절을 추가했습니다. 실제 stem 분리가 아닌 주파수·음색·지속음 기반 추정입니다.
- 저채도 커버의 밝기 범위를 다시 넓히고 Gaussian 중심 대비를 높여 그라디언트가 사라지는 현상을 줄였습니다.
- 일반 Blur 64px / 베일 12%, 가사 색 흐름 Blur 20px / 베일 4%로 조정했습니다.
- 52개 테스트 통과. SPEED DEMON 전체 178초를 새 분석기로 검증하고 6초 참고 영상을 생성했습니다.


## 1.6.0 · 2026-09-18

- Light / Dark 선택을 없애고 앨범에서 정한 배경·베일·텍스트 색상으로 통일했습니다.
- OKLCH로 배경 팔레트 명암·채도를 정돈하고, 색상각이 유지되는 sRGB gamut mapping을 추가했습니다.
- 앨범색이 은은하게 도는 흰 텍스트의 HEX / OKLCH 값을 패널, 설정 JSON, 생성 프레임의 shared plugin data에 제공합니다.
- 주기적으로 반복되는 Gaussian 영역을 합산해 색 경계의 기울기 꺾임을 줄였습니다.
- 기본 커버 0%, Mesh 100%, 베일 12%, Blur 64px로 원본의 거친 선·질감을 배경에서 제외했습니다.
- 기존 오디오 반응과 클릭한 순간의 포인트 저장을 유지했습니다. 테스트 45개 통과.


## 1.5.0

- 재생 중 배경을 생성하면 마지막으로 그려진 프레임의 내부 포인트 위치와 색을 저장합니다. 음악 재생은 계속됩니다.
- 일시정지한 상태의 생성, 네이티브 렌더 확인, PNG 생성과 설정 JSON에도 캡처한 프레임을 반영합니다.
- 네이티브 Shader의 외곽 포인트를 확장해 움직임으로 생기는 빈 가장자리를 방지합니다.
- 확장한 Mesh를 다시 읽을 때도 좌표 단위가 유지되도록 저장합니다.
- 비동기 생성 중 프레임이 바뀌는 경우 등을 검증하는 테스트를 추가했습니다.

## 1.4.0

- 일정한 간격과 크기로 반복되던 색 배치를 비대칭 배치로 변경했습니다.
- 각 색을 크기·비율·세기가 다른 두 영역에 나눠 반복 밀도를 낮췄습니다.
- 넓은 색 영역 사이에 여유를 두면서 저음·타격음에 따른 움직임은 유지했습니다.

## 1.3.0

- 색마다 하나였던 중심을 세 위치로 나눠 한쪽에 몰리는 느낌을 줄였습니다.
- 화면 밖에서도 색 분포가 이어지도록 처리했습니다.

## 1.2.0

- 작은 내부 변형을 화면 전체의 색 영역이 흐르고 휘어지는 방식으로 변경했습니다.
- 가사 모션 프리셋과 흐름 강도 0–180% 조절을 추가했습니다.
- 오디오 일시정지 시 현재 형태를 유지하도록 변경했습니다.

## 1.1.0

- 커버와 배치 설정에 따라 네이티브 Shader의 내부 포인트 위치도 바꾸도록 확장했습니다.
- Float 스펙트럼과 적응형 정규화로 저음·타격음 반응을 개선했습니다.
- ID 없는 로컬 개발 실행과 기존 레이어에서 Shader를 찾는 경로를 지원했습니다.

## 1.0.0

- 앨범 커버에서 주요 5색을 추출해 402 × 874 네이티브 Mesh Shader 배경을 생성합니다.
- Light / Dark, 커버·Mesh·상단 단색 불투명도, Background Blur를 조절할 수 있습니다.
